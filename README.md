# HTML Study Notes

These are my personal study notes from learning and working with HTML. They collect the document structure, semantic elements, forms, media, accessibility practices, and examples I want to keep in one practical reference.

## About these notes

I am building this collection as I study how browsers read and present HTML. The notes begin with a small valid document, explain why elements and attributes matter, and build toward complete page structures and accessible forms.

The examples use standard HTML and browser features. They do not require a framework or package installation. Each chapter includes practical markup, common mistakes to check, review questions, and links to the relevant reference pages.

## Core topics

- Write a complete HTML document and nest elements correctly
- Structure text, headings, lists, and links
- Add images, media, tables, and forms
- Use semantic landmarks and native interactive elements
- Add document metadata and load external resources correctly
- Build accessible controls with native HTML and ARIA where needed
- Validate forms and test pages in browsers

## How to use these notes

Open the first HTML file in a browser and follow the chapters in order, or use the index to jump to a specific element. Keep examples small, inspect the rendered result, and compare the markup with the browser accessibility tree.
